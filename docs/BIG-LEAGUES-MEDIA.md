# Big Leagues Media Discovery

The Media feed is generated by `scripts/big-leagues-media-scraper.js` every 20 minutes.

## Coverage

The discovery layer combines:

- Google News RSS for articles, beat coverage, team stories and indexed media.
- Reddit public search for new posts and discussions.
- Brave Search API, when configured, for broad web discovery including indexed Instagram, X, Threads, TikTok, Facebook, Bluesky, YouTube, photo pages and local/beat sites.
- X recent search, when configured, for direct X posts.
- YouTube Data API, when configured, for direct video discovery.

The system is intentionally provider-based so additional sources can be added without changing the Media feed schema.

## Fan-content policy

News, official team media and relevant video coverage may publish when the tracked player is clearly identified.

Fan-generated social content is stricter:

- clearly positive -> `feed.json`
- uncertain, neutral, mixed or potentially sarcastic -> `review.json`
- negative, insulting, hostile, DFA/cut/release sentiment or unrelated -> rejected and never written to the public feed

This means ambiguous fan content fails closed instead of appearing publicly.

## Output

- `data/big-leagues-media/feed.json` — public Media tab source
- `data/big-leagues-media/review.json` — hidden moderation queue
- `data/big-leagues-media/state.json` — local scan diagnostics

Each item includes player ID/name/label, source, provider, type, author, title, summary, URL, media URLs when available, publication/discovery time, metrics when available, and moderation reason.

## Optional GitHub Actions secrets

For maximum coverage, configure these repository Actions secrets:

- `BRAVE_SEARCH_API_KEY` — broad web/social discovery; highest-priority addition for Instagram/Threads/TikTok/Facebook and long-tail web results.
- `X_BEARER_TOKEN` — direct X recent-search coverage.
- `YOUTUBE_API_KEY` — direct YouTube discovery.

Without these secrets the workflow still runs with Google News and Reddit, but social/video coverage is narrower.
